# Light Profiles

[English version](README.md)

Light Profiles — интеграция Home Assistant для пресетов освещения. Она применяет настройки без редактирования автоматизаций, которые включают свет. У каждого профиля свой переключатель, уникальный числовой приоритет и группы светильников.

## Возможности

- Для каждой группы можно задать яркость, RGB или цветовую температуру и длительность перехода. Для совместимых светильников можно выбрать эффект отдельно.
- Яркость 0% гасит светильники группы, когда профиль вступает в силу, и оставляет их выключенными при командах включения, подходящих под фильтр.
- Отдельные группы можно временно отключать в их настройках. Остальные группы профиля продолжат работать.
- Команды включения можно фильтровать по устройству, сущности, автоматизации или сценарию. Включение из интерфейса Home Assistant настраивается отдельно.
- Для каждого светильника действует активный профиль с наивысшим приоритетом. Когда меняется профиль, горящие светильники сразу получают новые параметры. После выключения последнего применимого профиля светильник возвращается к состоянию и параметрам, заданным последними командами. Если команд не было, восстанавливается состояние до включения профиля.

Новые переключатели получают постоянные ID вида `switch.light_profile_k4f7m2ab` и `switch.light_profile_k4f7m2ab_group_n5q7t3cd`. В строке **«Идентификатор»** в настройках профиля или группы видны короткий код и текущий ID сущности. Общие переключатели сохраняют прежние ID. Если автоматизация использовала переключатель комнаты, после обновления выберите в ней переключатели нужных групп.

## Локальный Assist

В настройках группы можно выбрать **Пространство**. У каждой группы свой переключатель. Голосовая команда с названием комнаты управляет всеми группами, которые сейчас к ней привязаны.

- «Включи ночной режим» включает все группы профиля, в том числе группы без пространства
- «Включи ночной режим в гостиной» включает только группы гостиной

Используйте встроенный агент Home Assistant. Русские и английские команды регистрируются автоматически. Для нестандартных форм названий комнат можно добавить псевдоним пространства, например «в кабинете». Общий переключатель показывает «Вкл.», когда включены все части профиля.

## Примеры

| Профиль | Приоритет | Сценарий |
| --- | ---: | --- |
| Вечер | 10 | Приглушённый тёплый свет в гостиной |
| Ночь | 30 | Освещение ванной на 8% при срабатывании автоматизации от датчика движения |
| Кино | 50 | Приглушённый свет и эффект на совместимой светодиодной ленте |

Если «Вечер» и «Кино» включены и управляют одним светильником, применяется «Кино». После его выключения светильник возвращается к настройкам «Вечера».

## Установка

Скопируйте `custom_components/light_profile` в папку `custom_components` конфигурации Home Assistant. Перезапустите Home Assistant и откройте **Настройки → Устройства и службы → Добавить интеграцию → Light Profiles**. Задайте имя и приоритет профиля, добавьте группу и включите переключатель профиля.

Проверено на Home Assistant Core 2026.11.0 и 2026.11.3. Интеграция перехватывает `light.turn_on` и `light.toggle`, поэтому возможен конфликт с другими интеграциями, которые тоже заменяют эти обработчики.
